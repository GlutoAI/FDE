# Session Notes

Live scratchpad for a working session. Keeps agreed scope, assumptions, and progress in one place so the closing summary is accurate rather than reconstructed.

Reset this file at the start of each session.

## Agreed goal

> One sentence, in their words.

## Success looks like

> The observable outcome. What will be demonstrated, not what will be built.

## Must never

> The thing this must not do. From the "what's the worst thing this could do by mistake?" question.

## Assumptions

| # | Assumption | Confirmed? |
|---|---|---|
| 1 | | |

State these out loud when made. An unconfirmed assumption carried silently is the usual root cause of a wrong deliverable.

## Slices

| # | Slice | Status |
|---|---|---|
| 1 | | not started / in progress / done / **done and verified** |

"Done" and "done and verified" are different columns on purpose.

## Changed requirements

| When | What changed | What it changed in the build |
|---|---|---|

Log every mid-session redirect. Being able to say *"you asked for X at the twenty-minute mark, so I did Y"* is worth more than remembering it vaguely.

|---|---|

Only things that were executed and observed. This is the source for the closing "verified vs assumed" split.
